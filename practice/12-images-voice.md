# Практика 12. Изображения и голос

> 📘 Модуль курса: [8. Изображения и голос](../README.md#модуль-8-изображения-и-голос) · ⏱ 30 минут · 🎯 Уровень: новичок

## Цель

Генерировать изображения, которые можно использовать в работе, редактировать их итерациями, распознавать картинки и эффективно работать голосом.

---

## Формула промпта для изображения

```text
[Тип изображения] + [объект/сюжет] + [окружение] + [стиль] + [свет и цвет] +
[композиция и ракурс] + [формат] + [текст на картинке, если нужен] + [чего избегать]
```

## Упражнение 1. Обложка (как у этого курса)

```text
Обложка для GitHub-репозитория бесплатного курса «Excel для аналитиков».
Стиль: тёмный фон, неоновые зелёные акценты, стеклянные карточки (glassmorphism),
современный технологичный вид.
Композиция: слева — крупный заголовок «EXCEL PRO» и подзаголовок «полный курс на русском»;
справа — ноутбук с дашбордом и графиками; внизу — 3 карточки: «12 модулей»,
«Практика», «Шаблоны».
Формат 16:9, 1280×720. Весь текст на русском, без орфографических ошибок, крупный и читаемый.
Без логотипов чужих брендов.
```

После генерации — итерируйте точечно:

```text
Оставь всё как есть, но: 1) сделай заголовок крупнее, 2) убери лишние мелкие надписи
на экране ноутбука, 3) проверь каждое слово на опечатки.
```

## Упражнение 2. Инфографика и схемы

```text
Создай инфографику «5 шагов промпта» в вертикальном формате 4:5.
Каждый шаг — иконка, номер, заголовок (до 2 слов) и пояснение (до 6 слов):
Роль, Задача, Контекст, Формат, Ограничения.
Плоский стиль, 2 основных цвета: тёмно-синий и бирюзовый, белый фон.
```

> 💡 Для точных схем и диаграмм надёжнее попросить код Mermaid или SVG — текст будет без искажений.

## Упражнение 3. Распознавание изображений

Загрузите фото и попробуйте:

| Что загрузить | Промпт |
|---|---|
| Скриншот ошибки | «Что означает эта ошибка и как её исправить? Шаги по порядку» |
| Фото доски после встречи | «Расшифруй записи, структурируй в план с задачами» |
| График из отчёта | «Какие выводы следуют из графика? Что на нём может вводить в заблуждение?» |
| Чек / таблица | «Перенеси данные в таблицу CSV. Отметь, что не удалось разобрать» |
| Интерфейс сайта | «Сделай UX-аудит: 5 проблем по убыванию важности и как исправить» |
| Холодильник 🙂 | «Что можно приготовить из этих продуктов за 30 минут? 3 рецепта» |

## Упражнение 4. Редактирование своего изображения

```text
[прикреплено фото товара]
Сделай фото для карточки маркетплейса: белый фон, мягкая тень, товар по центру,
формат 3:4. Сам товар не изменяй — форма, цвет и надписи должны остаться точно такими же.
```

## Упражнение 5. Голосовой режим

Сценарии, где голос удобнее текста:

```text
Я сейчас за рулём/на прогулке. Давай устроим мозговой штурм идей для [задача].
Задавай мне по одному вопросу, а в конце пришли текстовое резюме с лучшими идеями.
```

```text
Проведи со мной пробное собеседование на позицию [роль]. Задавай вопросы по одному,
после моего ответа — коротко обратная связь. В конце — общая оценка и 3 совета.
```

```text
Помоги отрепетировать выступление. Я буду рассказывать, а ты в конце скажи:
где я затянул, какие слова-паразиты повторял, что было непонятно.
```

## Лучшие промпты для изображений

| Задача | Промпт |
|---|---|
| Фото-реализм | «Фотография, [объект], естественный свет, 35 мм, малая глубина резкости, без постобработки» |
| Иконки в стиле | «Набор из 6 иконок для [тема] в едином стиле: линейные, толщина 2px, один цвет» |
| Вариации | «Сделай 4 варианта этой концепции с разными цветовыми палитрами» |
| Мокап | «Покажи этот логотип на кружке, футболке и вывеске — 3 реалистичных мокапа» |
| Раскадровка | «Раскадровка видео из 6 кадров по сценарию: [сценарий], единый стиль» |

> ⚖️ Не генерируйте изображения реальных людей без согласия, чужие логотипы и персонажей, защищённых авторским правом.
