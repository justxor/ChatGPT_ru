# Практика 4. Анализ данных: от сырой таблицы к выводам

> 📘 Модуль курса: [5. Файлы и анализ данных](../README.md#модуль-5-файлы-и-анализ-данных) · ⏱ 45 минут · 🎯 Уровень: средний
> 📎 Файл для практики: [`data/sales.csv`](data/sales.csv) — 242 заказа за январь–июнь 2026 (данные вымышленные)

## Цель

Пройти полный цикл: загрузка → проверка качества → очистка → метрики → графики → выводы — и убедиться, что расчётам можно доверять.

## О датасете

| Колонка | Описание |
|---|---|
| `order_id` | номер заказа |
| `date` | дата заказа |
| `region` | регион |
| `channel` | Маркетплейс / Сайт / Офлайн |
| `category` | категория товара |
| `price_rub` | цена за единицу, ₽ |
| `qty` | количество |
| `discount_pct` | скидка, % |
| `returned` | был ли возврат |

> 🕵️ В файл специально добавлены **6+ проблем качества**: дубли, пропуски, опечатки в регистре, невозможная дата, выброс в цене, лишний пробел. Найдёт ли их ChatGPT?

---

## Шаг 1. Знакомство с данными

```text
[прикреплён sales.csv]
Ты — аналитик данных. Не делай выводов пока.
1. Опиши структуру: колонки, типы, число строк, период.
2. Проверь качество данных: дубли, пропуски, некорректные значения,
   выбросы, разное написание одних и тех же категорий.
3. Выведи таблицу проблем: колонка · проблема · сколько строк · примеры · как предлагаешь исправить.
Покажи код, которым проверял.
```

✅ **Ожидаемо найдётся:** 2 дубля заказов, пустой регион, пустое количество, «москва» в нижнем регистре, «маркетплейс » с пробелом, дата `2026-13-05`, цена `999999`.

## Шаг 2. Очистка

```text
Исправь проблемы так:
- дубли — удалить;
- регистр и пробелы — привести к единому виду;
- невозможную дату и выброс цены — исключить и вынести в отдельный список;
- пропуски — не заполнять выдуманными значениями, исключить из расчётов, где они мешают.
Покажи: было строк → стало строк, и что именно удалено.
Дай скачать очищенный файл sales_clean.csv.
```

## Шаг 3. Метрики

```text
Посчитай выручку = price_rub × qty × (1 − discount_pct/100), только по заказам без возврата.
Дай:
1. Выручку и число заказов по месяцам + рост месяц к месяцу в %.
2. Топ категорий по выручке и по среднему чеку.
3. Сравнение каналов: выручка, средний чек, доля возвратов.
4. Регион с самой высокой долей возвратов.
Все таблицы — с итоговой строкой.
```

## Шаг 4. Графики

```text
Построй 3 графика:
1. Линейный: выручка по месяцам.
2. Столбчатый: выручка по категориям, отсортировать по убыванию.
3. Сравнение каналов по доле возвратов.
Требования: подписи осей на русском, заголовок-вывод (например, «Электроника даёт 60% выручки»),
без лишних цветов. Дай скачать в PNG.
```

## Шаг 5. Выводы для руководителя

```text
На основе анализа напиши резюме для директора:
- 3 главных вывода (каждый с цифрой);
- 2 риска;
- 3 рекомендации с ожидаемым эффектом.
До 150 слов, простым языком. Отметь, какие выводы требуют больше данных.
```

## Шаг 6. Проверка — обязательна!

```text
Проверь свои расчёты:
1. Пересчитай общую выручку двумя разными способами и сравни.
2. Сумма выручки по месяцам = сумме по категориям = сумме по каналам?
3. Есть ли выводы, которые не следуют напрямую из данных?
```

И сами: откройте файл в Excel/Google Sheets и сверьте 2 цифры вручную.

## Лучшие промпты для работы с таблицами

| Задача | Промпт |
|---|---|
| Сводная | «Сделай сводную: строки — регион, столбцы — месяц, значения — выручка» |
| Когорты | «Посчитай удержание клиентов по месяцу первой покупки» |
| Аномалии | «Найди дни/строки, которые сильно выбиваются из нормы, и предложи объяснения» |
| Формула Excel | «Напиши формулу Excel, которая считает [что], если данные в столбцах [A–F]. Объясни по частям» |
| Прогноз | «Сделай простой прогноз на 3 месяца, покажи допущения и диапазон неопределённости» |
| Объединение | «Объедини два файла по `order_id`, покажи строки, которые не совпали» |

## Готово, если

- [ ] Найдены все проблемы качества (или вы нашли те, что модель пропустила).
- [ ] Получен очищенный файл и 3 графика.
- [ ] Итоговые суммы сходятся при проверке разными способами.
- [ ] Вы вручную сверили минимум 2 цифры.
