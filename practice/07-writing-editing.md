# Практика 7. Тексты и редактура

> 📘 Модули курса: [2. Промптинг](../README.md#модуль-2-промптинг) · [7. Canvas](../README.md#модуль-7-canvas-и-работа-с-документами) · ⏱ 40 минут · 🎯 Уровень: новичок → средний

## Цель

Писать с ChatGPT тексты, которые звучат как вы, а не как «нейросеть»: без клише, с конкретикой и в нужном тоне.

---

## Упражнение 1. Научите модель своему стилю

```text
Вот 3 моих текста:
"""[текст 1]"""
"""[текст 2]"""
"""[текст 3]"""

Проанализируй мой стиль: длина предложений, лексика, структура, юмор,
любимые обороты, чего я избегаю. Составь «паспорт стиля» на 10 пунктов,
который я смогу вставлять в промпты. Приведи по 1 примеру на каждый пункт.
```

Сохраните «паспорт стиля» в инструкции проекта (см. [Практику 3](03-personalization-projects.md)).

## Упражнение 2. Анти-ИИ редактура

```text
Отредактируй текст ниже. Правила:
- убери клише: «в современном мире», «играет ключевую роль», «не секрет, что»,
  «давайте разберёмся», «погрузимся», «уникальный», «революционный»;
- замени общие слова конкретикой: цифры, примеры, имена;
- сократи на 30% без потери смысла;
- разнообразь длину предложений;
- не добавляй новых фактов.
Покажи результат, затем список из 5 главных правок с объяснением.

Текст: """[текст]"""
```

## Упражнение 3. Один текст — пять форматов

```text
Вот статья: """[текст]""".
Сделай из неё:
1. Пост для Telegram (до 800 знаков).
2. Тред из 5 сообщений.
3. Письмо для рассылки с темой (3 варианта темы).
4. Сценарий 60-секундного видео: кадр · текст за кадром · надпись.
5. 3 тезиса для слайда.
Сохрани ключевую мысль, но адаптируй тон под каждую площадку.
```

## Упражнение 4. Письма в сложных ситуациях

```text
Помоги ответить на письмо. Ситуация: [клиент недоволен / коллега сорвал срок /
нужно отказать партнёру / попросить повышение].
Письмо, на которое отвечаю: """[текст]""".
Моя цель: [чего хочу добиться].
Чего нельзя: [ограничения].
Дай 3 варианта: дипломатичный, прямой, тёплый. Для каждого — риск.
```

## Упражнение 5. Заголовки и тексты, которые читают

```text
Тема статьи: [тема]. Аудитория: [кто].
Дай 15 заголовков по 5 формулам: цифра, вопрос, польза, провокация, история.
Оцени каждый по шкале 1–10 по «я бы кликнул» глазами аудитории.
Топ-3 улучши ещё раз.
```

## Упражнение 6. Работа в Canvas

```text
Открой этот текст в Canvas: """[текст]""".
Пройдись трижды:
1) структура — логичен ли порядок, нужны ли подзаголовки;
2) ясность — сложные предложения разбей;
3) грамотность — орфография и пунктуация.
После каждого прохода — краткий список изменений.
```

---

## Лучшие промпты для текстов

| Задача | Промпт |
|---|---|
| Сократить | «Сократи до [N] слов. Сначала скажи, что выкинешь, потом сокращай» |
| Тон | «Перепиши на тон: [дружелюбный эксперт]. Как будто объясняешь коллеге за кофе» |
| Структура | «Сначала предложи 3 варианта структуры, я выберу, потом пиши» |
| Слабые места | «Прочитай как скептичный читатель: где ты перестал бы читать и почему?» |
| Перевод | «Переведи на английский не дословно, а так, как написал бы носитель. Сохрани тон» |
| Корректура | «Только исправь ошибки. Стиль не меняй. Список исправлений — в конце» |

## Готово, если

- [ ] Есть «паспорт стиля», и тексты по нему звучат похоже на вас.
- [ ] Из одной статьи получились 5 форматов, которые не стыдно опубликовать.
- [ ] Вы перестали получать тексты со словами «уникальный» и «погрузимся».
