# Практика 6. Поиск и Deep Research

> 📘 Модуль курса: [6. Поиск и Deep Research](../README.md#модуль-6-поиск-и-deep-research) · ⏱ 40 минут (+ время работы исследования) · 🎯 Уровень: средний

## Цель

Научиться ставить исследовательские задачи так, чтобы получать отчёт с проверяемыми источниками, а не «пересказ первой страницы поиска».

## Когда что использовать

| Ситуация | Инструмент |
|---|---|
| Быстрый факт, курс, новость | Обычный поиск в чате |
| Сравнение 3–5 вариантов, обзор рынка | Поиск + думающая модель |
| Отчёт на 10+ источников, многоаспектный вопрос | Deep Research |

---

## Шаблон бриф-задания для Deep Research

```text
# Тема
[чётко сформулированный вопрос]

# Зачем
[какое решение я приму на основе отчёта]

# Рамки
- География: [страна/регион]
- Период: [например, 2024–2026]
- Что НЕ включать: [исключения]

# Источники
- Приоритет: официальные данные, отчёты компаний, исследования, отраслевые СМИ.
- Избегать: форумы, SEO-статьи без автора, пресс-релизы как единственный источник.

# Формат отчёта
1. Резюме на 5 пунктов.
2. Основные разделы: [список].
3. Сравнительная таблица: [какие колонки].
4. Что неизвестно / спорно.
5. Список источников со ссылками и датами.

# Требования
- Каждая цифра — со ссылкой на источник.
- Если источники противоречат — покажи оба значения.
- Отделяй факты от своих выводов.
```

## Упражнение 1. Исследование рынка

```text
Тема: рынок онлайн-образования для взрослых в России в 2025–2026.
Зачем: решаю, запускать ли платный курс по аналитике данных.
Вопросы:
1. Объём рынка и динамика, по каким оценкам.
2. 5 крупнейших игроков в нише «аналитика и данные»: цены, длительность, формат.
3. Какие форматы растут, какие падают.
4. Главные риски для нового игрока.
Формат: резюме, разделы по вопросам, таблица конкурентов, «что спорно», источники.
```

## Упражнение 2. Сравнение инструментов

```text
Сравни 4 сервиса для [задача, например: email-рассылок для малого бизнеса]:
[сервис 1], [сервис 2], [сервис 3], [сервис 4].
Критерии: цена за 5 000 контактов, бесплатный тариф, интеграции,
русский интерфейс, оплата из моей страны, отзывы пользователей за последний год.
Таблица + рекомендация для моего случая: [описание].
Указывай дату, на которую актуальна цена.
```

## Упражнение 3. Проверка утверждения (fact-check)

```text
Проверь утверждение: «[утверждение из соцсетей или статьи]».
1. Найди первоисточник.
2. Что подтверждается, что нет, что вырвано из контекста?
3. Вердикт: правда / частично правда / неправда / недостаточно данных.
4. Источники с датами.
```

## Упражнение 4. Аудит отчёта

После того как Deep Research выдал отчёт:

```text
Проверь свой отчёт:
1. Выпиши 10 ключевых цифр, для каждой — источник и дату.
2. Отметь цифры, у которых источник старше 2 лет или вторичный.
3. Какие выводы опираются на один источник?
4. Что нужно перепроверить человеку в первую очередь?
```

Откройте минимум 3 ссылки и убедитесь, что цифры там действительно есть.

## Лучшие промпты для поиска

| Задача | Промпт |
|---|---|
| Свежие новости | «Что изменилось в [тема] за последний месяц? Только события с датами и ссылками» |
| Обзор литературы | «Найди 5–7 исследований о [тема], для каждого: авторы, год, выборка, главный вывод, ограничения» |
| Due diligence | «Собери публичную информацию о компании [название]: юр. данные, новости, отзывы сотрудников и клиентов, риски» |
| Лучшие практики | «Как решают [задача] ведущие компании? 5 кейсов с источниками и цифрами результата» |
| Объяснение спора | «В чём суть дискуссии о [тема]? Аргументы каждой стороны и на какие данные они опираются» |

## Готово, если

- [ ] Вы написали бриф по шаблону для своей реальной задачи.
- [ ] Получили отчёт, где у каждой цифры есть источник.
- [ ] Лично проверили 3 ссылки и нашли (или не нашли) расхождения.
