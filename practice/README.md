# 🧪 Практикум ChatGPT PRO: файлы с примерами и лучшими промптами

> Практическая часть курса [ChatGPT PRO — полный курс на русском](../README.md).
> 13 практик с разборами «плохой → хороший промпт», учебные файлы для отработки, ответы для самопроверки и библиотека из 50 лучших промптов.

## Как проходить

1. Откройте практику и прочитайте разбор примеров.
2. Скачайте учебный файл из папки [`data/`](data/), если он нужен, и загрузите его в ChatGPT.
3. Скопируйте промпт, выполните его, сравните результат с блоком «✅ Проверка».
4. Повторите на **своих** задачах и данных — так навык закрепляется.
5. Отметьте пункты «Готово, если» и сохраните удачные промпты в свою библиотеку.
