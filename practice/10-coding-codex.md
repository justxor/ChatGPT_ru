## Упражнение 1. Скрипт с нуля (даже если вы не программист)

```text
Напиши Python-скрипт, который:
1. Читает sales.csv (колонки: order_id, date, region, channel, category, price_rub, qty, discount_pct, returned).
2. Удаляет дубли по order_id, некорректные даты и строки без qty.
3. Считает выручку = price_rub * qty * (1 - discount_pct/100) без возвратов.
4. Сохраняет report.xlsx с листами: «По месяцам», «По категориям», «По каналам».
Требования: pandas + openpyxl, понятные комментарии на русском,
обработка ошибки «файл не найден». В конце — как установить зависимости и запустить.
```

## Упражнение 6. Задача для Codex

Codex работает с репозиторием как агент: читает код, вносит изменения, запускает тесты. Ставьте задачу как тикет:

```text
## Задача
Добавить в CLI-утилиту флаг --format с вариантами csv|json|xlsx для экспорта отчёта.

## Контекст
- Точка входа: src/cli.py, логика отчёта: src/report.py
- Сейчас экспорт только в csv (функция export_csv).

## Требования
- По умолчанию csv — обратная совместимость.
- Для xlsx использовать openpyxl (уже есть в зависимостях).
- Неизвестный формат → понятная ошибка и код выхода 2.

## Критерии готовности
- Тесты в tests/test_cli.py на каждый формат и на ошибку.
- Все существующие тесты проходят.
- README: раздел «Экспорт» обновлён.

## Не трогать
- Публичные сигнатуры в src/report.py.
```

## Упражнение 7. Первый вызов API

Запустите [`examples/api_example.py`](examples/api_example.py): он отправляет отзывы из [`data/reviews.txt`](data/reviews.txt) в модель и получает структурированный JSON с темой и тональностью каждого отзыва.

```bash
pip install openai
export OPENAI_API_KEY="sk-..."      # ключ храните в переменных окружения, не в коде
python practice/examples/api_example.py
```

Задание: доработайте скрипт с помощью ChatGPT — пусть сохраняет результат в CSV и печатает сводку по темам.

## Лучшие промпты для разработчиков

| Задача | Промпт |
|---|---|
| Регулярка | «Напиши regex для [что]. Дай 5 строк, которые должны совпасть, и 5 — которые не должны» |
| SQL | «Вот схема таблиц: [DDL]. Напиши запрос: [что]. Объясни план и предложи индекс» |
| Рефакторинг | «Отрефактори, сохранив поведение. Сначала перечисли code smells, потом изменения маленькими шагами» |
| Документация | «Напиши docstring и README-раздел для этого модуля: назначение, пример, параметры, исключения» |
| Миграция | «Перепиши с [библиотека v1] на [v2]. Отметь изменения в поведении» |
| Архитектура | «Предложи 2 варианта архитектуры для [задача], сравни по сложности, стоимости и масштабируемости» |
