> 50 проверенных промптов по категориям. Копируйте, подставляйте своё в `[квадратные скобки]`, сохраняйте лучшие в инструкции проекта.

## 🧰 Универсальные

**1. Сначала вопросы**

```text
Мне нужно [задача]. Прежде чем отвечать, задай до 5 уточняющих вопросов
с вариантами ответов. Работай только после моих ответов.
```

**2. Эксперт-консилиум**

```text
Рассмотри вопрос [вопрос] глазами трёх экспертов: [эксперт 1], [эксперт 2], [эксперт 3].
Каждый — 3–5 тезисов. Затем найди, в чём они согласны и где расходятся, и дай итоговую рекомендацию.
```

**3. Самопроверка**

```text
Проверь свой предыдущий ответ: найди 3 слабых места (факты, логика, полнота),
оцени уверенность в ключевых утверждениях и выдай исправленную версию.
```

**4. Резюме для нового чата**

```text
Сожми наш диалог в конспект для продолжения в новом чате: цель, контекст,
принятые решения, текущий результат, открытые вопросы, следующий шаг. До 200 слов.
```

**5. Объясни как профи**

```text
Объясни [тема] сначала в одном предложении, затем на бытовом примере,
затем подробно для специалиста. Отметь распространённые заблуждения.
```

## ✍️ Тексты

**6. Анти-клише редактура**

```text
Отредактируй текст: убери клише и канцелярит, замени общие слова конкретикой,
сократи на 30%, не добавляй новых фактов. В конце — список главных правок.
Текст: """[текст]"""
```

**7. Три тона**

```text
Перепиши текст в трёх вариантах: официальный, дружелюбный, прямой и короткий.
Текст: """[текст]"""
```

**8. Паспорт стиля**

```text
Проанализируй 3 моих текста и составь «паспорт стиля» из 10 пунктов с примерами,
чтобы ты мог писать так же. Тексты: """[...]"""
```

**9. Сложное письмо**

```text
Помоги ответить на письмо. Моя цель: [цель]. Нельзя: [ограничения].
Дай 3 варианта (дипломатичный, прямой, тёплый) и риск каждого.
Письмо: """[текст]"""
```

**10. Заголовки**

```text
Дай 15 заголовков к статье о [тема] для [аудитория] по 5 формулам:
цифра, вопрос, польза, провокация, история. Оцени каждый 1–10 и улучши топ-3.
```

## 📊 Данные и аналитика

**11. Аудит данных**

```text
[файл] Опиши структуру данных и найди проблемы качества: дубли, пропуски,
выбросы, разное написание. Таблица: колонка · проблема · кол-во · как исправить. Покажи код.
```

**12. Полный анализ**

```text
[файл] Посчитай ключевые метрики по [измерение], найди 5 инсайтов с цифрами,
построй 3 графика с заголовками-выводами. В конце — что требует дополнительных данных.
```

**13. Формула Excel**

```text
Напиши формулу Excel/Google Sheets: [что посчитать]. Данные: [где какие столбцы].
Объясни формулу по частям и дай вариант для случая, если есть пустые ячейки.
```

**14. Резюме для директора**

```text
На основе анализа напиши резюме для руководителя: 3 вывода с цифрами,
2 риска, 3 рекомендации с ожидаемым эффектом. До 150 слов, без терминов.
```

**15. Проверка расчётов**

```text
Пересчитай итог двумя разными способами. Сходятся ли суммы по разным разрезам?
Какие выводы не следуют напрямую из данных?
```

## 💼 Работа и управление

**16. Протокол встречи**

```text
[расшифровка] Сделай протокол: решения, задачи (что · кто · срок),
открытые вопросы, риски. Даты — только из текста. Плюс сообщение в чат команды до 80 слов.
```

**17. Матрица решений**

```text
Помоги выбрать между [варианты]. Предложи 6 критериев с весами, оцени варианты,
дай итоговую таблицу и скажи, что должно измениться, чтобы победил другой вариант.
```

**18. Pre-mortem**

```text
Представь, что проект [описание] провалился через 6 месяцев.
Назови 7 вероятных причин, для каждой — ранний сигнал и как предотвратить сейчас.
```

**19. Делегирование**

```text
Помоги делегировать задачу [задача] сотруднику [уровень]. Составь поручение:
цель, ожидаемый результат, критерии готовности, срок, ресурсы, точки контроля.
```

**20. Обратная связь**

```text
Помоги дать обратную связь сотруднику: [ситуация]. Используй модель SBI
(ситуация — поведение — влияние). Дай текст разговора и ответы на 3 возможные реакции.
```

## 📣 Маркетинг и продажи

**21. Портрет клиента**

```text
Опиши 3 сегмента клиентов для [продукт]: кто они, задача (Job to be done), боли,
возражения, где их найти, какие слова они используют. Отметь, что нужно проверить интервью.
```

**22. Ценностное предложение**

```text
Сформулируй 5 вариантов ценностного предложения для [продукт] для [сегмент]
по схеме «помогаем [кому] [сделать что] без [боль]». Оцени каждый по ясности и отличию.
```

**23. Контент-план**

```text
Контент-план на месяц для [площадка] для [аудитория]: 12 публикаций.
Таблица: дата · рубрика · тема · формат · цель (охват/доверие/продажа) · призыв.
```

**24. Скрипт продаж**

```text
Скрипт звонка для [продукт]: приветствие, 5 квалифицирующих вопросов,
презентация через выгоды, ответы на 7 типичных возражений, закрытие.
```

**25. Разбор конкурента**

```text
[ссылка или описание] Проанализируй предложение конкурента: позиционирование,
цены, сильные и слабые стороны, на чём мы можем выиграть. Отдели факты от предположений.
```

## 🎓 Обучение

**26. Сократ**

```text
Научи меня [тема] методом Сократа: по одному вопросу, жди ответа, поправляй.
Через 10 вопросов подведи итог: что понял, где пробелы.
```

**27. Учебный план**

```text
План изучения [навык] за [N] недель, [часы] в неделю, уровень [уровень].
Неделя: тема · бесплатные материалы · практика · самопроверка. Финал — мини-проект.
```

**28. Экзамен**

```text
Проведи экзамен по [тема]: 10 вопросов разного формата, по одному,
с оценкой после каждого. В конце — слабые темы и карточки для повторения.
```

**29. Карточки Anki**

```text
Сделай 20 карточек в CSV «вопрос;ответ» из конспекта. Один факт на карточку,
ответ до 15 слов. Конспект: """[текст]"""
```

**30. Конспект книги**

```text
7 ключевых идей книги [название]: суть, пример, как применить в [моя сфера].
Отметь, где не уверен в точности пересказа.
```

## 💻 Код

**31. Скрипт под задачу**

```text
Напиши скрипт на [язык], который [задача]. Входные данные: [формат].
Требования: комментарии, обработка ошибок, инструкция по запуску.
```

**32. Отладка**

```text
Ошибка: """[traceback]""" Код: """[фрагмент]""" Окружение: [...].
Назови 3 вероятные причины по убыванию вероятности и исправь только нужные строки.
```

**33. Код-ревью**

```text
Код-ревью как senior: 🔴 баги/безопасность, 🟡 производительность, 🟢 читаемость.
Для каждого: строка · проблема · исправление. """[код]"""
```

**34. Тесты**

```text
Напиши тесты [фреймворк] для функции: обычные случаи, граничные, некорректный ввод.
Понятные имена, параметризация. """[функция]"""
```

**35. SQL**

```text
Схема: [DDL]. Напиши SQL-запрос: [что]. Объясни логику и предложи индекс для ускорения.
```

## 🔎 Исследования

**36. Бриф Deep Research**

```text
Тема: [вопрос]. Зачем: [решение]. Рамки: [география, период, исключения].
Формат: резюме, разделы, сравнительная таблица, что спорно, источники с датами.
Каждая цифра — со ссылкой; противоречия источников — показывай оба значения.
```

**37. Фактчекинг**

```text
Проверь утверждение «[утверждение]»: первоисточник, что подтверждается, что вырвано
из контекста, вердикт (правда / частично / неправда / недостаточно данных), ссылки.
```

**38. Сравнение сервисов**

```text
Сравни [сервисы] для [задача] по критериям: [список]. Таблица + рекомендация для
моего случая: [описание]. Указывай дату актуальности цен.
```

**39. Обзор исследований**

```text
Найди 5–7 исследований о [тема]: авторы, год, выборка, метод, вывод, ограничения.
Затем — где учёные согласны, а где нет.
```

**40. Аудит отчёта**

```text
Выпиши 10 ключевых цифр отчёта с источниками и датами. Отметь устаревшие,
вторичные и опирающиеся на один источник. Что проверить в первую очередь?
```

## 🧘 Личная продуктивность

**41. План недели**

```text
Задачи: [список]. Встречи: [список]. Время для глубокой работы: [часы].
Распредели по дням с приоритетами, оставь 20% буфера. Что делегировать или убрать?
```

**42. Разгрести голову**

```text
Вот всё, что у меня в голове: """[поток мыслей]""". Разложи на: задачи (с ближайшим
действием), идеи, тревоги (что я могу контролировать, а что нет), решения, которые нужно принять.
```

**43. Подготовка к разговору**

```text
Мне предстоит разговор с [кто] о [тема]. Цель: [цель]. Помоги подготовиться:
мои аргументы, их вероятные возражения, первая фраза. Потом сыграй собеседника.
```

**44. Путешествие**

```text
План поездки в [город] на [N] дней для [кто], бюджет [сумма], интересы: [список].
По дням: утро · день · вечер, логистика между точками, где поесть. Отметь, что бронировать заранее.
```

**45. Финансовый порядок**

```text
Мои расходы за месяц: [таблица]. Разбей по категориям, найди 3 места для экономии
и предложи простую систему бюджета. (Это не финансовая консультация.)
```

## 🧠 Мета-промпты

**46. Улучши мой промпт**

```text
Оцени мой промпт 1–10 по ясности, контексту, формату и ограничениям,
затем перепиши на 10/10. Пометь [в скобках], что мне нужно дописать.
Промпт: «[промпт]»
```

**47. Создай шаблон**

```text
Я регулярно делаю [задача]. Задай 5 вопросов, затем напиши многоразовый промпт
с [переменными], разделами «Роль», «Вход», «Шаги», «Формат», «Проверка» и 2 примерами.
```

**48. Инструкции для GPT**

```text
Напиши инструкции для Custom GPT, который [задача]: роль, входные данные, алгоритм,
формат, ограничения, чек-лист качества, пример. Затем — 10 тестовых запросов для проверки.
```

**49. Чего я не спросил**

```text
Какие важные вопросы по теме [тема] я не задал, но должен был бы?
Назови 5 и кратко ответь на каждый.
```

**50. Оппонент**

```text
Вот моя позиция: [позиция]. Найди самые сильные контраргументы — не соломенные чучела,
а то, что сказал бы умный оппонент. Затем — как я могу усилить свою позицию.
```

## Фразы-усилители

Добавляйте в конец любого промпта:

| Цель | Фраза |
|---|---|
| Точность | «Если не уверен — так и скажи. Не выдумывай» |
| Проверяемость | «Указывай источник для каждого факта» |
| Краткость | «Без вступлений и повторения вопроса» |
| Глубина | «Подумай шаг за шагом, прежде чем дать итоговый ответ» |
| Действие | «В конце — один конкретный следующий шаг» |
| Альтернативы | «Дай 3 варианта: осторожный, смелый, неожиданный» |
